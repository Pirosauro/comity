# Comity Framework

A modular, type-safe web framework built on Hono, designed for building scalable web applications and APIs.

## 🚀 Quick Start

```bash
# Install dependencies
pnpm install

# Run tests
pnpm test

# Start development
cd examples/admin
pnpm dev
```
