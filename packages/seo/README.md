# @comity/seo

Reusable SEO abstractions for Comity domain modules.

## Purpose

`@comity/seo` defines structured SEO metadata models shared by Comity modules.

## Public API

- `OpenGraphModel`
- `SeoModel`
- `StructuredDataModel`
- `TwitterCardModel`
