# @comity/graphql-client-ws

WebSocket transport for `@comity/graphql-client`.

---

## Purpose

Provides a GraphQL transport implementation that executes operations over GraphQL WebSocket clients.

---

## Scope

This package:

- ✅ implements the GraphQL transport contract
- ✅ exposes the WebSocket transport class

This package does NOT:

- ❌ define GraphQL client contracts
- ❌ own query building
- ❌ embed application-specific GraphQL policy
