# @comity/router-path-to-regexp

Path-to-regexp router implementation for Comity.

---

## Purpose

Provides a router implementation that uses `path-to-regexp` while conforming to the `@comity/router` contracts.

---

## Scope

This package:

- ✅ implements `PathRouter`
- ✅ adapts routing behavior to `@comity/router`

This package does NOT:

- ❌ redefine router contracts
- ❌ own application routing policy
- ❌ render HTTP responses
