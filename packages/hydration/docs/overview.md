# @comity/hydration — Overview

`@comity/hydration` defines the contracts used to hydrate islands in Comity applications.

It provides the structural pieces required to discover islands, describe hydration strategies, and serialize island contracts safely.

---

## What it models

- island contracts
- hydration strategies
- island discovery
- island hydration
- hydration lifecycle

---

## What it is not

- not an HTML renderer
- not a data-loading layer
- not a framework-specific adapter
- not a business-policy module
