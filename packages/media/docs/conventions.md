# @comity/media — Conventions

This document defines the conventions for `@comity/media`.

---

## 1. Scope

The package is concept-only.

It MUST NOT grow into a storage or processing layer.

---

## 2. Public API

- the root entrypoint is the public surface
- no internal sub-entrypoints are currently exposed

---

## 3. Media Model

- the media model is shared and framework-agnostic
- changes to the model are contract changes
