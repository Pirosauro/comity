# @comity/media

Media contracts for Comity.

---

## Purpose

Defines the stable media model used by higher-level packages.

---

## Scope

This package:

- ✅ exports the `MediaModel` contract

This package does NOT:

- ❌ implement media storage
- ❌ render media
- ❌ manage upload or delivery policy
