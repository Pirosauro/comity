# @comity/sql

SQL boundary module for Comity.

## Purpose

`@comity/sql` defines the contracts used to talk to SQL databases without
binding Comity to a concrete driver or ORM.

## Public API

- `SqlClient`
- `SqlClientOptions`
- `SqlQuery`
- `SqlTransaction`
- `SqlResult`
- `SqlOperationResult`
- `error` subpath
- `hooks` subpath
