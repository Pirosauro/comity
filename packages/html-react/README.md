# @comity/html-react

React integration for `@comity/html`.

## Purpose

`@comity/html-react` provides React-based renderers and layout helpers for the
Comity HTML model.

## Public API

- `ReactStaticHtmlRenderer`
- `useLayout`
- `setup` subpath
- `streaming` subpath
