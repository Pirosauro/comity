# @comity/hydration-preact — Overview

`@comity/hydration-preact` adapts the Comity hydration model to Preact.

It provides a Preact island component, a registry for island loaders, and a runtime factory for client-side hydration.

---

## What it includes

- island component rendering
- component registry wiring
- hydration runtime creation

---

## What it does not include

- hydration contract definition
- island discovery policy
- application data loading
- HTML document rendering
