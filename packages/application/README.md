# @comity/application

Application-layer utilities for Comity.

## Purpose

`@comity/application` provides helper contracts for application composition and
result resolution. It sits at the application boundary and depends on the lower
Comity layers it needs.

## Public API

- `ApplicationContract`
- `ApplicationResolver`
- `ApplicationResult`
- `resolveContract`
- `errors` subpath
