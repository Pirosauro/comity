# @comity/catalog

Catalog abstractions for Comity domain modules.

## Purpose

`@comity/catalog` defines category, product, inventory, and pricing contracts
used by storefront and commerce-related modules.

## Public API

- category and product repositories
- category/product/inventory/price models
- repository context
- setup tokens and module types
