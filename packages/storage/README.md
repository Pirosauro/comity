# @comity/storage

Storage module for Comity.

## Purpose

`@comity/storage` defines storage contracts, stores, and setup wiring for
Comity applications.

## Public API

- `Storage`
- `StorageStore`
- `DefaultStorage`
- storage option types
- `error` subpath
- `hooks` subpath
- `setup` subpath
- `stores` subpath
