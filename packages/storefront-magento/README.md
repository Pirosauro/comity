# @comity/storefront-magento

Magento GraphQL adapter for `@comity/storefront`.

## Purpose

`@comity/storefront-magento` connects the storefront core to Magento GraphQL
data sources and cached repository implementations.

## Public surface

- `setup` subpath
- adapter wiring types

## Source structure

- repositories
- internal mapping and GraphQL helpers
- cached repository implementations
