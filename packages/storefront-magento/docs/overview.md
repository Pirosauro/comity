# @comity/storefront-magento — Overview

`@comity/storefront-magento` adapts Magento GraphQL data to Comity storefront
contracts.

## Source areas

- Magento-specific repository implementations
- GraphQL helpers and schema helpers
- URL rewriting integration
- setup metadata and adapter options

## What it does not include

- storefront domain ownership
- rendering logic
- generic Magento framework abstractions
