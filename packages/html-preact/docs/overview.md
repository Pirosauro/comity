# @comity/html-preact — Overview

`@comity/html-preact` adapts Preact rendering to the Comity HTML model.

It provides renderers and helpers that produce HTML through the contracts exposed by `@comity/html`.

---

## What it includes

- static rendering
- streaming rendering
- Preact layout helpers

---

## What it does not include

- data loading
- repository access
- HTML contract definition
- application-specific view orchestration
