# @comity/auth-tokens

Token envelope and facade helpers for Comity authentication flows.

## Purpose

`@comity/auth-tokens` provides token-facing contracts and a default facade used
by auth-related packages.

## Public API

- `AuthTokenEnvelope`
- `AuthTokenFacade`
- `IssueTokensInput`
- `DefaultAuthTokenFacade`
