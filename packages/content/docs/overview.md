# @comity/content — Overview

`@comity/content` provides the contract layer for content-oriented pages and blocks.

It gives applications a stable shape for describing content repositories and the models they return.

---

## What it models

- pages
- blocks
- breadcrumbs
- navigation
- repository context

---

## What it is not

- not a renderer
- not a repository implementation
- not a search engine
- not a presentation layer
