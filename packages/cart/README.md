# @comity/cart

Cart abstractions for Comity domain modules.

## Purpose

`@comity/cart` defines cart contracts and cart-related models that can be used
by higher-level commerce modules.

## Public API

- `CartAddItemInput`
- `CartRepository`
- `CartModel`
- cart item models
- `error` subpath
