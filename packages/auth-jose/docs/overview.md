# @comity/auth-jose — Overview

`@comity/auth-jose` integrates the `@comity/auth` module with JOSE-based token
handling.

## What it includes

- `JoseAuthTokenService`
- `JoseAuthTokenServiceOptions`
- setup metadata and hooks
- adapter-specific helpers for token/session mapping

## What it does not include

- auth domain semantics
- standalone public error contracts
- application orchestration
