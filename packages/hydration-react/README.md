# @comity/hydration-react

React hydration integration for Comity.

## Purpose

`@comity/hydration-react` bridges the Comity hydration layer with React-based
components and runtime helpers.

## Public API

- `Island`
- `IslandComponentLoader`
- `IslandComponentRegistry`
- `createHydrationRuntime`
- `setup` subpath
