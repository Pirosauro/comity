# @comity/storefront

Generic storefront contracts for Comity.

## Purpose

`@comity/storefront` defines page composers, page models, and context contracts
used by storefront applications and adapters.

## Public API

- default page composers
- category/content/product/search page contracts
- storefront context contracts
- setup tokens and module types
