# @comity/i18n

Internationalization module for Comity.

## Purpose

`@comity/i18n` provides locale, translation, and loader contracts for
Comity-based applications.

## Public API

- `I18nFacade`
- `I18nLoader`
- `Locale`
- `I18nLocaleResolver`
- `I18nResolveContext`
- `Translator`
- `error` subpath
- `hooks` subpath
- `setup` subpath
